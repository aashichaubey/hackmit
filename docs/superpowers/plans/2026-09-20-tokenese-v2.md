> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Discover and serve a legend-free meeting-fact encoding that uses fewer actual model input tokens without losing checked facts or answers.

**Architecture:** Extend the existing validated fact representation, generate a bounded catalog of deterministic whole-meeting encodings, screen them locally with the pinned tokenizer, and qualify one profile with model QA on meeting-disjoint data. Compile facts once per meeting in Streamlit session state, then compare raw notes, Tokenese V2, and compression baselines for both single and batched questions.

**Tech Stack:** Python 3.11+, Pydantic 2, OpenAI Python SDK 2, tiktoken, pytest, Streamlit, existing LLMLingua-2 and optional Bear-2 adapters.

**Spec:** `docs/superpowers/specs/2026-09-20-tokenese-v2-design.md` (derived from the pasted Tokenese V2 proposal).

## Global Constraints

- Pin extraction and answer evaluation to `gpt-4.1-mini-2025-04-14`; record model and tokenizer with every profile. A different model needs a new search.
- Send no grammar legend with V2. Keep the same answer instruction and output schema across candidates in a comparison.
- Preserve people, task/object terms, negation, and date modifiers. Never silently change a proposal into a decision.
- Search only development data, choose on validation, then run the fresh test once. V1's previously used test is development diagnostic data only.
- `τ = 99%` means observed gold-fact QA accuracy of at least 119/120 on validation and again on test, with zero new critical errors. It does not imply a statistical 99% guarantee.
- Report tokenizer counts for local screening and actual `usage.input_tokens` for finalists. End-to-end totals include extraction once per meeting and all answering calls. Report Bear-2 provider usage separately.
- Keep pasted meetings and credentials out of saved reports. Store only public bundled data in V2 reports.
- Follow the current simple Python style: small functions, no implementation comments, no new model-training or database framework.
- This workspace currently has no `.git` directory. Each task has a test/review checkpoint; commits become possible only after the project is placed under version control.

```python
Kind = Literal["proposal", "decision", "action", "agreement", "disagreement", "blocker", "status", "question"]

V2_EXTRACTION_INSTRUCTION = "Extract explicit actions, proposals, decisions, agreements, disagreements, blockers, statuses, and open questions. Keep names, task terms, negation, and date modifiers literal. Owner and deadline are fields, not fact kinds. Include a short exact source quote for every fact. Do not turn proposals into decisions or uncertain statements into facts."
V2_ANSWER_INSTRUCTION = "Answer only from these meeting facts. The assignee of an action is its owner. For who/when, return only the exact name/date. For yes/no, answer yes or no only when explicit. If absent or uncertain, set found=false and answer='not found'. A proposal is not a decision; blocked work is not completed."

def v2_extraction_prompt(notes: str) -> str:
    return f"{V2_EXTRACTION_INSTRUCTION}\n<meeting>\n{notes}\n</meeting>"

def v2_answer_prompt(context: str, question: str) -> str:
    return f"{V2_ANSWER_INSTRUCTION}\n<meeting_facts>\n{context}\n</meeting_facts>\nQuestion: {question}"

def source_positions(notes: str, facts: MeetingFacts) -> list[int]:
    positions = []
    cursor = 0
    for fact in facts.facts:
        position = notes.find(fact.source_quote, cursor)
        if position < 0:
            position = notes.find(fact.source_quote)
        if position < 0:
            raise ValueError("An extracted source quote is absent from the meeting notes")
        positions.append(position)
        cursor = position + len(fact.source_quote)
    return positions

def extract_v2_facts(client, notes: str, model: str = MODEL):
    facts, usage = parse_response(client, v2_extraction_prompt(notes), model, MeetingFacts)
    source_positions(notes, facts)
    return facts, usage
```

    verb_style: str

```python
def qualifies(candidate_rows, raw_rows, english_rows, required_correct=119):
    if len(candidate_rows) != len(raw_rows) or len(candidate_rows) != len(english_rows):
        return False
    if any(row.get("error") for row in candidate_rows):
        return False
    if sum(row["correct"] for row in candidate_rows) < required_correct:
        return False
    if sum(row["input_tokens"] for row in candidate_rows) >= min(
        sum(row["input_tokens"] for row in raw_rows),
        sum(row["input_tokens"] for row in english_rows),
    ):
        return False
    return not any(
        old["correct"] and not new["correct"] and new["kind"] in {"owner", "deadline", "negation", "decision", "unknown"}
        for old, new in zip(raw_rows, candidate_rows)
    )
```
