Evidence notes

What these numbers measure

The gold-fact diagnostic reports 105/120 correct answers and 85.553% less answer input versus raw. Its extraction and annotation limitations prevent a product savings claim. The frozen evaluation is marked incomplete.

The published-data pilot uses 32 training questions with a matched raw baseline. Input tokens: 34,589 → 33,659. Cost: $0.0194628 → $0.0187356. Token-overlap F1: 29.86% → 26.11%. These are development results, not held-out qualification.

  • Gold-fact evidence: reports/evolution/metrics.json
  • Pilot evidence: reports/publicqa/README.md
  • KV caching and fine-tuning have no measured results in this deck.
  • The KV-cache proposal is distinct from the existing local response replay cache.

Compare the same questions and model conditions. Include one-time compilation, repeated answer requests, actual cached-token pricing, output tokens, and training cost amortized over a stated workload. Never add individual savings percentages to estimate combined savings.
